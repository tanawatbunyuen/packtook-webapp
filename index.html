เริ่มต้นใช้งาน

  1. ใช้ Chrome หรือ Edge บน Desktop และเปิดเว็บไซต์ผ่าน HTTPS
  2. หน้า Packing กดเปิดกล้อง และอนุญาตสิทธิ์กล้อง
  3. กดเลือกโฟลเดอร์เพื่ออนุญาตให้บันทึกไฟล์ในเครื่อง
  4. กรอกชื่อพนักงาน จากนั้นสแกน Barcode และกด Enter เพื่อเริ่ม
  5. สแกน Barcode เดิมอีกครั้งเพื่อหยุดและบันทึกไฟล์
  6. ดูรายการที่ Dashboard หรือเปิดไฟล์จากโฟลเดอร์ในเครื่องโดยตรง

ข้อจำกัด Demo: ยังไม่มี Backend, ระบบสมาชิกจริง, การคิดค่าบริการจริง และการบังคับโควตาข้ามเครื่อง ไม่ควรใช้เป็นหลักฐานสำคัญในการปฏิบัติงานจริงก่อนผ่านการทดสอบความเสถียร
