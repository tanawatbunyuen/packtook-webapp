## ผลงาน

- Landing Page ภาษาไทยสำหรับร้านค้าออนไลน์: Premium Navy, Cyan and Mint
- Responsive Desktop / Tablet / Mobile + ARIA Hamburger Menu (ESC and link selection close menu)
- Hero แนะนำ Barcode → REC → scan again → SAVE และภาพจำลองหน้าระบบที่แสดงว่าเป็นภาพจำลองอย่างชัดเจน
- Feature cards, 4 steps, target users, 6 plan pricing cards, 7 FAQs, Pre-launch call to action
- ใช้โลโก้และ Eagle Mascot เดิมจาก public/assets
- Thai metadata, Open Graph title/description, skip-link, visible keyboard focus, prefers-reduced-motion
- ไม่มี Firebase API/Analytics/Email collection/Live Checkout ในหน้า Marketing

## Cloud Shell: ทดสอบก่อน Deploy (ไม่กระทบ Production)

    cd ~/packtook-production-v621
    git fetch origin feature/v6.5.1-marketing-website
    git switch -c feature/v6.5.1-marketing-website FETCH_HEAD
    git branch --show-current
    cd production

    node scripts/verify.mjs packtook-prod-01
    node scripts/test-marketing-website.mjs
    node scripts/test-public-registration.mjs
    node scripts/test-onboarding-ui.mjs
    node --check public/assets/site.js
    bash -n scripts/deploy-marketing-prelaunch.sh

หาก Local Branch มีอยู่แล้ว ใช้ git switch feature/v6.5.1-marketing-website แล้ว git pull --ff-only origin feature/v6.5.1-marketing-website โดยตรวจสอบ git status ก่อน

## Manual QA

1. เปิด Desktop 1440px / 1024px และ Mobile 390px / 360px; ไม่มี horizontal overflow
2. Hero, logo, Eagle Mascot, Website Mock Dashboard โหลดครบและอ่านง่าย
3. Mobile Navigation เปิด/ปิดได้ เลือกเมนูแล้วปิด กด ESC แล้วปิดและโฟกัสกลับไปที่ปุ่ม
4. CTA in-page links นำไป Section ถูกต้อง; Beta Login เปิด https://packtook-prod-01-app.web.app/
5. ราคาและเงื่อนไข TEST ครบ 6 แผน ไม่สื่อว่ารับเงินจริงแล้ว
6. FAQ 7 ข้อเปิด/ปิดได้และเข้าถึงด้วยคีย์บอร์ด
7. Pre-launch Notice, noindex/robots.txt ยังคงปิด SEO จนอนุมัติ Public Launch
8. ไม่มีการส่งข้อมูลส่วนบุคคลหรือทำ Checkout จากหน้า Marketing
9. เช็ก Browser Console และ Network; ไม่มี error หรือการร้องขอที่ไม่คาดคิด
10. ทดสอบบน Browser ที่รองรับกล้องแยกจากหน้า Marketing; ฟีเจอร์ Packing อยู่ใน Customer App เดิม

## Deploy เฉพาะ Marketing Prelaunch เมื่อ Manual QA ผ่าน

    cd ~/packtook-production-v621/production
    bash scripts/deploy-marketing-prelaunch.sh packtook-prod-01

Script ยืนยัน Project ID และ Firebase Hosting Target mapping ก่อน Deploy เฉพาะ hosting:marketing.
ยืนยันด้วยข้อความ: DEPLOY-PACKTOOK-MARKETING-PRELAUNCH

ไม่ Deploy App, Owner, Functions, Firestore Rules หรือการจ่ายเงิน และไม่เปิด Public Signup

## Public Launch Checklist ภายหลัง

- ปิด V6.5 Firebase Auth/Email/App Check Integration QA และเตรียมเอกสาร Privacy/Terms ที่อนุมัติ
- ยืนยันราคา เครดิต ระยะเวลา วิธีจ่าย และเงื่อนไขแพ็กเกจที่ใช้จริง
- อนุมัติข้อมูลผู้ให้บริการ ช่องทางติดต่อ นโยบายความเป็นส่วนตัว และกระบวนการยกเลิก
- เมื่อเปิดสมัครจริง: เปลี่ยน CTA เป็นหน้า Signup ที่ทำงานจริง, อัปเดตสถานะ, robots, noindex และ SEO
- ตรวจ Mobile / Performance / Accessibility และการเก็บ Analytics/Cookie Consent (ถ้ามี)
