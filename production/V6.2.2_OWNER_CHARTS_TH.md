# PACKTOOK V6.2.2 — Owner Revenue Charts

**Branch:** `feature/v6.2.2-owner-revenue-charts`
**Firebase Project:** `packtook-prod-01`
**Status:** GitHub source updated. Code/static/mocked-DOM tests pass. **Not deployed automatically**.

## What changed

- Revenue page now renders three charts instead of large numeric tiles and monthly rows/table:
  - Accumulated recorded `Live`, `Test`, `Unclassified` paid transactions (horizontal bars).
  - Purchase-plan breakdown of recorded `Live` and `Test` transactions (grouped horizontal bars). Unclassified amounts cannot be broken down per plan using current API, so not invented.
  - Monthly 12-month grouped bar chart with separate Live / Test / Unclassified colors and tooltips.
- Zero revenue renders explanatory empty chart states, without fake bars or sales.
- Firebase `ownerAnalyticsRevenue` callable and Production Customer/credits/payments unchanged.
- All revenue comes only from `accounts/{uid}/billingRequests` Paid Firestore records; not real-time verified cash or Omise payout.
- All charts use DOM text nodes (no `innerHTML`), no third-party graph library or new network dependency.

## Deploy **ONLY** the Owner Hosting website

