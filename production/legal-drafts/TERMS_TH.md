# PACKTOOK — ร่างข้อกำหนดการให้บริการ (สำหรับตรวจสอบก่อนเผยแพร่)
**สถานะ: DRAFT / ยังไม่ใช่ข้อตกลงที่มีผลจริง**

ผู้ให้บริการ: [ชื่อธุรกิจ/เลขทะเบียน/ที่อยู่/ช่องทางติดต่อ]
วันเริ่มใช้: [วันที่]

## 1. บริการ
PACKTOOK เป็นระบบช่วยบันทึกงานแพ็กสินค้าด้วย Barcode และกล้องบนเบราว์เซอร์ที่รองรับ โดยจัดเก็บไฟล์วิดีโอในโฟลเดอร์ที่ผู้ใช้เลือกบนเครื่อง และบันทึกข้อมูลการใช้งานบางส่วนบน Cloud

## 2. เงื่อนไขการใช้บริการ
ผู้ใช้ต้องมีสิทธิ์ในการบันทึกและจัดเก็บข้อมูลที่เกี่ยวข้องกับงานแพ็กสินค้า และปฏิบัติตามกฎหมาย/นโยบายองค์กรของตนเอง ต้องรักษาความปลอดภัยของบัญชี อุปกรณ์ และโฟลเดอร์วิดีโอ

## 3. การสมัคร แพ็กเกจ เครดิต และวันหมดอายุ
[เติมราคา/ภาษี/สิทธิ์วิดีโอ/ระยะเวลา/อุปกรณ์/เงื่อนไขการต่ออายุที่อนุมัติแล้ว]
การจองเครดิตระหว่างบันทึกจะต้องสรุปผลตามสถานะไฟล์และระบบ ควรชี้แจงกรณีคืนเครดิตและกู้คืนรายการค้างอย่างชัดเจน

## 4. ข้อจำกัดการจัดเก็บ
ไฟล์วิดีโอไม่ถูกสำรองอัตโนมัติบน Server ของ PACKTOOK ตามสถาปัตยกรรมปัจจุบัน ประวัติบางส่วนอยู่ใน IndexedDB ของโปรไฟล์เบราว์เซอร์ ไม่รับประกันว่าจะย้ายข้ามเครื่องหรือกู้กลับได้หากล้างข้อมูลเบราว์เซอร์
[กำหนดระดับบริการ การรับประกันและข้อจำกัดความรับผิดที่สอดคล้องกับกฎหมาย]
