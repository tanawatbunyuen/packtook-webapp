# PACKTOOK V6.4.3 — Sidebar ยุบ/ขยาย + แท็บแก้ปัญหาเบื้องต้น

Branch: `feature/v6.4.3-sidebar-troubleshooting`  
Base: `feature/v6.4.2-same-plan-renewal-reminders`  
Firebase target: `packtook-prod-01` (Production **Beta**)  
Scope: Customer UI + read-only on-page troubleshooting only. **No Recording / Omise / Billing / Wallet Cloud Functions modified.**  
Status: committed on GitHub; **do not assume deployed**. Live payments still disabled; QR uses Omise Test.

## สิ่งที่เพิ่ม

1. ปุ่ม ☰ ที่ Topbar เพื่อยุบ Sidebar (Desktop ~310 → 82px) และขยายกลับได้ทันที พร้อมบันทึกค่าไว้ใน localStorage ของ Browser นั้น
2. Sidebar ยุบแล้วเหลือไอคอน + Tooltip; เข้าถึงเมนู Packing, Dashboard, Packages, Users, Help และ Troubleshooting ได้ต่อเนื่อง
3. จอไม่เกิน 700px ยุบ Sidebar แล้วซ่อนแถบเมนูเพื่อเพิ่มพื้นที่ และเปิดอีกครั้งด้วย ☰; เมื่อเลือกเมนูจะยุบโดยอัตโนมัติ
4. แท็บใหม่ **แก้ปัญหาเบื้องต้น** มี 14 ปัญหาที่พบบ่อย แบ่งกล้อง/Barcode/โฟลเดอร์/เครดิต/อุปกรณ์/QR/การเชื่อมต่อ พร้อมช่องค้นหา, ตัวกรองหมวด, วิธีตรวจ 3 ขั้นตอน และลิงก์กลับไปแท็บที่เกี่ยวข้อง
5. ป้องกันการทำงานเสี่ยง: FAQ ไม่สั่ง Reset Credit, ไม่แก้ Subscription, ไม่สร้าง QR และไม่ลบไฟล์ / IndexedDB; แจ้งว่าควรใช้ Recovery หลังตรวจสอบว่าไม่มีวิดีโอสำเร็จแล้วเท่านั้น

## V6.4.2 Production Beta — 3 ข้อที่ยังรอยืนยัน

ผู้ทดสอบรายงานผ่าน **6/9** ข้อ: ข้อ 1, 2, 3, 6, 8, 9. ยังไม่ยืนยัน **4, 5, 7** (ไม่ถือว่า Fail โดยอัตโนมัติ).

- **#4 แจ้งเตือนก่อนหมดอายุ 7 วัน:** ทดลองกับบัญชี Beta ที่แยกต่างหาก/ข้อมูลจำลองที่สิทธิ์เหมาะสม เปิดหน้าเว็บตอนเหลือ 7×24 ชั่วโมงหรือน้อยกว่า ต้องเห็น Banner และปุ่มไป Packages; เมื่อจ่ายต่ออายุแล้ว Banner หาย
- **#5 ก่อน 7 วันไม่มี Banner:** ตอนเหลือ 8 วัน ต้องไม่มี Banner; Free Account ก็ไม่ควรแสดง
- **#7 เก็บเครดิต 10 วัน:** บัญชีหมดอายุ → ใช้อัดวิดีโอใหม่ไม่ได้ แต่เครดิตที่ยกยอดได้ต้องยังคงอยู่จนถึง 10×24 ชั่วโมงหลังหมดอายุ, หลังจากนั้นไม่ถูกนำไปรวมเครดิตเมื่อซื้อใหม่; Scheduler ภายหลังต้องล้างยอดจริงพร้อม Audit

ข้อ #4/#5/#7 มี unit/mock tests อยู่ใน `test-renewal-notice.mjs`, `test-package-policy.mjs` และ `test-promptpay.mjs`; **ยังต้องตรวจ behavior ของ Production Beta**. ห้ามเปลี่ยน `planExpiresAt` หรือ `creditWalletRemaining` ของลูกค้าจริงเพื่อเร่งการทดสอบ. ใช้บัญชีทดสอบที่ยืนยันสิทธิ์พร้อมสำรองข้อมูลและกระบวนการคืนค่าที่ผ่านการอนุมัติ หรือใช้ Emulator เพื่อเช็ก boundary โดยไม่แตะ Production.
