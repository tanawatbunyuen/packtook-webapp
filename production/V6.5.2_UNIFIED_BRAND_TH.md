# PACKTOOK V6.5.2 — Marketing & Customer Unified Brand

Branch: `feature/v6.5.2-unified-customer-brand`
Base: `feature/v6.5.1-marketing-website`
Scope: **Marketing Hosting UI only**, without modifying Customer/Owner/Payment/Recording systems.
Status: Committed in GitHub; **NOT DEPLOYED**.

## เหตุผล

เว็บไซต์ V6.5.1 ใช้สีเขียว Mint และการ์ด Navy มากเกินไป ในขณะที่หน้า PACKTOOK Customer Login และ Dashboard ใช้ CI จริงเป็น **Navy #071632 / Blue #096bfa / Cyan #08b7eb / พื้นหลังเทาอมฟ้า #f4f7fc / การ์ดสีขาว #ffffff / สีตัวอักษร #102449**

## สิ่งที่ปรับ V6.5.2

1. Header และ Footer ใช้ `packtook-lockup`, `packtook-mark`, `packtook-type` เหมือน Customer (ชื่อ PACKTOOK + subtitle PACKING VIDEO RECORDER)
2. Logo SVG และ Eagle Mascot เป็น **ไฟล์เดียวกันตรงทุก byte** กับ Customer App
3. Hero ใช้สีน้ำเงินเข้มแบบ Customer Login, หัวข้อ “บันทึกทุกการแพ็กสินค้า อย่างมืออาชีพ” และคำขวัญนกอินทรี “สายตาอินทรี มั่นใจทุกออเดอร์”
4. Primary CTA ใช้ gradient เดียวกับปุ่ม Login ของ Customer: `#00a6f2 → #2250ef`
5. Dashboard Mockup ภายใน Hero เปลี่ยนจาก dark UI เป็น dark-blue sidebar + white cards + light `#f4f7fc` workspace แบบหน้า PACKING จริง โดยมีป้าย **ภาพจำลอง** เหมือนเดิม
6. Features, How It Works, Pricing และ FAQ ใช้การ์ดพื้นขาว ขอบสี `#e1e9f5` มุมโค้ง 12–20px และไอคอน Blue/Cyan เหมือน Customer
7. ช่วงเปรียบเทียบสินค้า, Hero และ Launch CTA ใช้ Navy Blue เพื่อคงความพรีเมียมโดยไม่กลายเป็นคนละแบรนด์
8. Responsive 980px/640px, keyboard focus, reduced-motion ยังคงอยู่

แยก Brand Overrides เป็น `public/assets/customer-brand.css` สำหรับให้ปรับ CI ในอนาคตโดยไม่ต้องแก้ Style หน้า Customer

## Deploy (หลัง Manual Acceptance ผ่านเท่านั้น)

```bash
cd ~/packtook-production-v621/production
bash scripts/deploy-marketing-prelaunch.sh packtook-prod-01
```

คำยืนยัน: `DEPLOY-PACKTOOK-MARKETING-PRELAUNCH`

**สคริปต์ Deploy เฉพาะ `hosting:marketing`** ไม่ Deploy `hosting:app`, `hosting:owner`, Functions, Firestore Rules, Auth หรือ Omise

Marketing URL: `https://packtook-prod-01.web.app/`

หลัง Deploy ให้ใช้ Ctrl+Shift+R แล้วเทียบหน้า Marketing กับ Customer: `https://packtook-prod-01-app.web.app/`
