## Isolation
- Firebase emulator project ID exactly `demo-packtook-v72`.
- Firebase Auth loopback at `127.0.0.1:19099`, Firestore at `127.0.0.1:18080`; no Hosting, Functions, Payment or Storage emulator required.
- Real Firebase Admin SDK is initialized explicitly to demo project; emulator host environment is strictly checked before any writes. No Google Application Credentials passed to emulator CLI.
- The production handler source is run in a Node VM with mocked callable transport and a test HMAC; its `productionProjectReady()` env requirement is satisfied ONLY inside the VM with mocked production env values. In contrast the actual SDK runs only against demo Auth/Firestore emulators.
- Creates temporary demo Auth users, test consent records, quota counters, device, recording metadata and control doc; never a real user. No video file is written.
