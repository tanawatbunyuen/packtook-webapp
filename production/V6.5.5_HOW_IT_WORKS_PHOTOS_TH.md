# PACKTOOK V6.5.5 — How it works ภาพสถานีแพ็กสินค้าสมจริงทั้ง 4 ขั้นตอน

**Branch:** `feature/v6.5.5-how-it-works-real-photos`
**Base:** `feature/v6.5.4-hero-photo-type-scale`
**Scope:** Marketing website ONLY (`production/public`). No changes to Customer App, Cloud Functions, Firestore, Omise, credits, Owner, or real customer data.
**Status:** Code and 4 optimized photos committed in GitHub; NOT DEPLOYED to Firebase Hosting.

## What's changed

เปลี่ยนไอคอน 4 ช่องในส่วน **How It Works** เป็นภาพสไตล์ภาพถ่ายจริงที่สร้างจาก Generative AI:

| Step | Image in GitHub | Action shown |
|---|---|---|
| 01 / READY | `public/assets/howto-ready.webp` | พนักงานที่สถานีแพ็ก เลือกพื้นที่จัดเก็บและเตรียมกล้อง |
| 02 / START | `public/assets/howto-scan.webp` | สแกน Barcode เพื่อเริ่มอัด |
| 03 / STOP | `public/assets/howto-save.webp` | สแกน Barcode เดิมเมื่อแพ็กเสร็จเพื่อหยุด/บันทึก |
| 04 / REVIEW | `public/assets/howto-review.webp` | ค้นหาและเล่นวิดีโอย้อนหลังบน PACKTOOK Dashboard |

All images are 720×540 WebP (4:3) at ~34–36 KB each, optimized for fast page load. Actual binary images are committed in GitHub; NO separate ZIP upload needed.

## UI

- The four card titles, numbering, explanatory text and existing branding remain unchanged.
- New `figure.step-photo` with descriptive `alt`, `loading="lazy"`, `decoding="async"`, and intrinsic width/height.
- Styles in `public/assets/howto-photos.css` loaded after other marketing CSS for responsive cards.
- Desktop: 4 columns with clear landscape images; tablet: 2 columns; mobile: 1-column stacked cards with full-width images.
- Section includes a clear disclaimer: image scenes were generated by AI for illustration; **not real customer photography or real app screenshots**.
- Marketing stays pre-launch / noindex and does not allow public signup or live payment.

## Marketing ONLY deploy (after successful test)

```bash
cd ~/packtook-production-v621/production
bash scripts/deploy-marketing-prelaunch.sh packtook-prod-01
```

The script asks for `DEPLOY-PACKTOOK-MARKETING-PRELAUNCH` and deploys ONLY `hosting:marketing`. No User App, Owner, payment, credits, or Firebase functions updated.

After successful deploy: open https://packtook-prod-01.web.app/#how-it-works then hard reload with Ctrl+Shift+R.

### Rollback

Roll back Marketing Hosting only via Firebase Hosting release history or deploy the last approved Marketing branch. Never use `firebase deploy` without an explicit `--only hosting:marketing` scope.
