This reads Cloud Functions metadata for 12 guarded Beta exports plus two Admission exports and `publicSignupStatus`; local Git and Firebase configuration; HTTP Public Safety status. **No Cloud writes and no redeploy**.

The script intentionally does not declare Production ready merely because Functions are ACTIVE. It reports an explicit `review` array, including missing revision references, unexpected service account identities or absent codebase labels. A service revision reference in `gcloud functions describe` can be absent even if Cloud Run maintains a revision history. In that case separately inspect Cloud Run revision metadata with read-only commands and record exact last-known-good image/source artifacts. Do NOT infer rollback from Git SHA alone.

## PASS interpretation
- `blocking: []`: no detected mismatch in fresh Public Safety, source bindings, or function active baseline.
- `review`: unresolved items that must be settled before deployment. `metadataGatePass` remains false as long as any review item exists.
- `deploymentApproved:false`, `prodWrites:false`, `decision:NO_GO_CONTROLLED_PILOT` are **always correct**, even if metadata is clean.
- Negative fixtures only prove test logic; check real Cloud Shell results before any owner-approved deployment.
