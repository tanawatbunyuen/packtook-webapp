### Cloud Shell QA workflow

1. Download ZIP from ChatGPT. Cloud Shell top-right menu → **Upload file** → choose `packtook_v654_hero_asset.zip` (default destination: Cloud Shell HOME).

2. Fetch code:

```bash
cd ~/packtook-production-v621
git fetch origin feature/v6.5.4-hero-photo-type-scale
git switch feature/v6.5.4-hero-photo-type-scale 2>/dev/null || \
git switch -c feature/v6.5.4-hero-photo-type-scale FETCH_HEAD
git branch --show-current
git status --short
```

3. Extract ZIP into repo root:

```bash
unzip -o "$HOME/packtook_v654_hero_asset.zip" -d "$HOME/packtook-production-v621"
ls -lh production/public/assets/packtook-hero-photo.webp
```

4. Run tests:

```bash
cd production
node scripts/verify.mjs packtook-prod-01
node scripts/test-marketing-typography.mjs
node scripts/test-marketing-workflow-comparison.mjs
node scripts/test-marketing-website.mjs
node scripts/test-marketing-brand-parity.mjs
node --check public/assets/hero-photo.js
bash -n scripts/deploy-marketing-prelaunch.sh
```

5. Visually QA first. After approval, deploy **Marketing Hosting ONLY** using the guarded script:

```bash
bash scripts/deploy-marketing-prelaunch.sh packtook-prod-01
```
